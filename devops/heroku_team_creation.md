# Heroku Team Creation

1. Estimate costs for server setup based on the recommended dynos for staging, production, databases, and plugins.
2. Send a message to the partner with the estimated costs and schedule a time to get on a call and create the Heroku team together and add a payment method. Heroku does not allow creating a team without a payment method, so it will either need to be done this way or a temporary RoleModel credit card will need to be entered to begin configuration.
3. Log into the it support account on Heroku.
4. Open the teams dropdown and click "Add new"
5. Name the team, and with the partner, enter the partner's credit card so that they will be responsible for payments under that Heroku team.
